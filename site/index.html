Features

Everything a design library needs, in one native app.

Falcon keeps your references, assets and inspiration in a library you can search in seconds, and stays out of your way while you work.

01 · Collect

Bring files in any way you like

Drop files and folders onto the window, paste with ⌘V, or open files with Falcon. Each item gets a thumbnail and a colour palette automatically.

  • Images, SVG and animated GIF
  • PDF, PSD, AI, HEIC, RAW and video through macOS QuickLook
  • Imports run in the background with a progress bar
02 · Organise

Folders, tags and rules that work for you

Nest folders, pin the ones you use to Quick Access, and let smart folders gather items that match your rules.

  • Rename, merge, star and delete tags across the whole library
  • Edit tags, folders and ratings on many items at once
  • Notes, source URLs, ratings and a Trash you can restore from
03 · Search

Find anything by word, rule or colour

Type a few words, or combine them with OR, NOT and quoted phrases. The filter bar narrows by tag, folder, shape, rating, type, notes and URL.

  • Colour search ranks images by how close their dominant colours are
  • Click a swatch in the inspector to find similar images
  • Sort by date, title, size, dimensions or rating
04 · Browse

Four layouts and a viewer that keeps up

Waterfall keeps every image's shape, Justified fills each row, Grid lines up square cards, and List shows the details.

  • Zoom around the pointer, pan, fit and actual size
  • Step through items with the arrow keys
  • Drag items out into Finder, Figma or Photoshop

Developers

Script your library.

The same engine runs the app, a command-line tool and a local HTTP API, so scripts, plugins and AI agents can work with your library too.

# Create a library and add files
$ falcon new ~/Pictures/Moodboard.library
$ falcon import ~/Pictures/Moodboard.library \
    poster.png --tag type --tag 1960s
$ falcon info ~/Pictures/Moodboard.library
items:   1 (0 in trash)
folders: 0
tags:    2
# Talk to the running app over HTTP
$ curl -X POST localhost:41596/api/item/addFromPath \
    -d '{"path": "/tmp/ref.jpg", "tags": ["ref"]}'
{"status":"success","data":"MVP8K2…"}

$ curl -X POST localhost:41596/api/v2/item/query \
    -d '{"query": "poster OR flyer -draft"}'
