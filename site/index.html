Falcon is a free, open-source asset manager for everyone.

Collect, tag, search and browse your images, PDFs, fonts, audio and video in one library. Native apps for macOS, Windows and Linux, built in Rust for speed.

Download

Download Falcon

Free. One download for Macs, one for Windows and two for Linux, all holding the same app. To update, download the new version and install it the same way; Falcon doesn't update itself yet.

Mac · .dmg

For Macs with Apple Silicon (M1 or newer) and macOS 12 or later. There is no download for Intel Macs yet.

Install Open Falcon-arm64.dmg and drag Falcon to Applications.

First launch Falcon isn't notarised by Apple, so macOS refuses it at first. Click Open Anyway in System Settings ▸ Privacy & Security; on macOS 14 and earlier you can instead right-click Falcon and choose Open. Or run this in Terminal:

xattr -dr com.apple.quarantine \
  /Applications/Falcon.app
Download .dmg

Windows · installer

For 64-bit Windows on Intel and AMD. Only Windows 11 has been tried so far.

Install Run Falcon-x86_64-setup.exe. It installs for you alone, without admin rights, in %LOCALAPPDATA%\Programs\Falcon, and adds Falcon to the Start menu. To remove it, use Add or remove programs; your libraries and settings stay.

First launch Falcon isn't code-signed, so Windows SmartScreen warns you the first time. Click More info, then Run anyway.

Download installer

Linux · AppImage

For most distributions from 2022 or newer, on 64-bit Intel and AMD.

Install Nothing to install: make the file executable and run it.

chmod +x Falcon-x86_64.AppImage
./Falcon-x86_64.AppImage

First launch Opens straight away. It isn't added to your app menu.

Download AppImage

Linux · .deb

For Ubuntu, Debian and distributions based on them, from 2022 or newer, on 64-bit Intel and AMD.

Install Installs Falcon with an entry in your app menu.

sudo apt install ./Falcon-x86_64.deb

First launch Open Falcon from the app menu. To remove it later, run sudo apt remove falcon.

Build from source

Build Falcon yourself

Falcon is open source. You need Rust 1.89 or newer on any of the three; each card has the rest.

Mac

Needs Apple's command line tools (xcode-select --install). Video plays through macOS; FFmpeg, for the formats macOS can't play, is optional.

Build and run

git clone https://github.com/AhmedKhan-GH/falcon
cd falcon
cargo run --release -p falcon-app

Package it Build FFmpeg, then make Falcon-arm64.dmg in target/macos:

scripts/build-ffmpeg.sh
scripts/package-macos.sh

Linux

Needs these packages (Debian and Ubuntu names; other distributions use their own). FFmpeg plays video on Linux, so it is built first.

sudo apt install pkg-config libasound2-dev \
  nasm zlib1g-dev python3-venv

Build and run

git clone https://github.com/AhmedKhan-GH/falcon
cd falcon
scripts/build-ffmpeg.sh
cargo run --release -p falcon-app

Package it Make Falcon-x86_64.AppImage and Falcon-x86_64.deb in target/linux:

scripts/package-linux.sh

Windows

Needs Rust for the MSVC toolchain, with Visual Studio's C++ build tools. FFmpeg plays video on Windows, so it is built first, in an MSYS2 UCRT64 shell that can also see cargo and a Windows Python (set MSYS2_PATH_TYPE=inherit before opening it), with these packages:

pacman -S --needed make diffutils tar xz curl \
  mingw-w64-ucrt-x86_64-gcc \
  mingw-w64-ucrt-x86_64-binutils \
  mingw-w64-ucrt-x86_64-nasm \
  mingw-w64-ucrt-x86_64-zlib

Build and run

git clone https://github.com/AhmedKhan-GH/falcon
cd falcon
scripts/build-ffmpeg.sh
cargo run --release -p falcon-app

Package it In the same shell, make Falcon-x86_64-setup.exe in target/windows. The script fetches NSIS itself:

scripts/package-windows.sh

While it is in development, Falcon only opens libraries inside ~/Falcon Sandbox (%USERPROFILE%\Falcon Sandbox on Windows). The README has the command-line tool and more.

Features

Features

Falcon keeps your references, assets and inspiration in one library on disk. These are the parts that work today; the status section below lists what is still missing.

01 · Collect

Bring files in any way you like

Drop files and folders onto the window, paste with ⌘V, open files with Falcon, or keep the always-on-top collect window open beside your browser. Each item gets a thumbnail and a colour palette automatically.

  • Images, SVG and animated GIF
  • PDF, PSD, AI, HEIC, RAW and video, with macOS QuickLook where it helps
  • Screen capture of an area, a window or the whole screen
  • Import folders with their folder tree, and skip or keep files already in the library
  • A panel lists imports that failed, with the reason
  • Waveform thumbnails for audio and specimen thumbnails for fonts
  • Camera, duration, tempo and font details, and IPTC and XMP keywords as tags
  • Imports run in the background with a progress bar
  • Images, video, audio, fonts, documents, 3D models and design files, listed in FORMATS.md
02 · Organise

Folders, tags and smart folders

Nest folders, pin the ones you use to Quick Access, and let smart folders gather items that match your rules. Folders take icons, colours, covers, passwords, auto-tags for items added to them and a manual item order.

  • Rename, merge, star and delete tags, and sort them into tag groups
  • Edit tags, folders and ratings on many items at once
  • Undo and redo for edits
  • A tag picker with suggestions, and marquee selection in the grid
  • Actions you define with steps, a shortcut and a menu entry
  • A Duplicates page for identical files and similar pictures
  • Export items or folders to a folder, CSV or a pack another library can import, or as JPG, PNG or WebP at a chosen size
  • Notes, source URLs, ratings and a Trash you can restore from
03 · Search

Search by word, filter or colour

Type a few words, or combine them with OR, NOT and quoted phrases; small typos still match. The filter bar narrows by tag, folder, shape, rating, type, notes, URL, date, duration, tempo, camera and font.

  • Colour search ranks images by how close their dominant colours are
  • Click a swatch in the inspector to find similar images
  • Save a set of filters and reuse it
  • Sort by date, title, size, dimensions or rating
04 · Browse

Four layouts

Waterfall keeps every image's shape, Justified fills each row, Grid lines up square cards, and List shows the details.

  • Hover over a card for a larger preview
  • Drag items out into Finder, Figma or Photoshop, or copy their paths, names, thumbnails or Base64
  • Keep several libraries open and switch between them
  • Dark, light, gray, blue and purple themes, or follow macOS
  • The interface in eight languages, with sound effects and preferences panes
  • A native macOS menu bar, keyboard shortcuts for most actions, and rebinding in Preferences
05 · View

A viewer for images, video, audio, PDFs, fonts, 3D and web pages

Items open inside the window between the sidebar and the inspector, and one button hides both panels. Zoom around the pointer, pan, fit or see an image at actual size, and step through items with the arrow keys.

  • Images, PSD and AI files open at full resolution
  • Video plays with a control bar and timed comments, with an FFmpeg fallback that includes AV1
  • PDFs open in a reader with find, text selection, spreads, rotation and print
  • 3D models turn and zoom with their textures, and IFC models load through web-ifc
  • Text files open in an editor, and web pages and MHTML files show live
  • Audio plays over its waveform, and fonts show a live specimen
  • Comment on a region of an image
  • Rotate, flip and crop originals
  • Open an item in its default app or another app

Developers

Command-line tool and HTTP API

The same engine runs the app, a command-line tool and a local HTTP API, so scripts and other tools can work with your library too.

# Create a library in the sandbox and add files
$ lib=~/"Falcon Sandbox"/Moodboard.library
$ falcon new "$lib"
$ falcon import "$lib" \
    poster.png --tag type --tag 1960s
$ falcon info "$lib"
items:   1 (0 in trash)
folders: 0
tags:    2
# Talk to the running app over HTTP
$ curl -X POST localhost:41596/api/item/addFromPath \
    -d '{"path": "/tmp/ref.jpg", "tags": ["ref"]}'
{"status":"success","data":"MVP8K2…"}

$ curl -X POST localhost:41596/api/v2/item/query \
    -d '{"query": "poster OR flyer -draft"}'
Status

Early alpha

Falcon is being built feature by feature. PARITY.md checks each planned local feature in falcon's code: about 99% are done, and the rest are listed there with the reason. FORMATS.md lists the file formats it handles, and ROADMAP.md what is left and what comes later.

Working today

  • Import with thumbnails, colour palettes, folder trees and screen capture
  • Folders, tags with a tag picker, tag groups, smart folders, Quick Access, undo
  • Keyword, filter and colour search, saved filters
  • Four layouts, marquee selection, hover preview and themes
  • Viewers for images, video, audio, fonts, text, PDFs, 3D models, PSD, AI and web pages
  • Duplicates, region comments, rotate, flip and crop
  • Actions and Export in Format, built into the app
  • Preferences panes, sound effects and eight interface languages
  • Command-line tool and local HTTP API

Not there yet

  • Some File > New templates, such as Keynote and Sketch
  • Sharp zoom in PPT files past 8192 px
  • A check on screen of some newer features
  • Plugins
  • Native review of the translations
  • An Intel Mac build, a notarised Mac app, a signed Windows installer, and some features on Windows and Linux

Falcon is early alpha and unsigned. While falcon is in development, the app and the command-line tool only open libraries inside ~/Falcon Sandbox (%USERPROFILE%\Falcon Sandbox on Windows), or the folder set in FALCON_SANDBOX. To try falcon on an existing library, copy it there first. See Sandbox in the docs.
