Symphonia is covered by the Mozilla Public License 2.0 (<https://mozilla.org/MPL/2.0/>). Falcon uses it unmodified, as published on crates.io; the source code of every MPL-covered file is available from the repository above and from each crate's page on crates.io (for example <https://crates.io/crates/symphonia/0.5.5>). Falcon's own files are not covered by the MPL.

The audio test fixtures in `crates/falcon-library/testdata/audio` were made for falcon's tests from a synthesised tone. Some were encoded with the pure-Rust `rusty_mp3` 1.0.5 and `rusty_vorbis` 0.1.2 encoders (Apache-2.0, [github.com/Remade-With-Rust/remade_ffmpeg_rs](https://github.com/Remade-With-Rust/remade_ffmpeg_rs)), which are not linked into falcon, and the rest with macOS `afconvert`.

web-ifc and its header-only dependencies are not part of falcon's source tree. `scripts/fetch-web-ifc.sh` downloads each one as a GitHub source tarball at the tag or commit above, checks it against a pinned SHA-256 (listed in that script) and unpacks it into `target/web-ifc`; `crates/falcon-ifc/build.rs` then compiles web-ifc's sources, unmodified, and links them with falcon's own `crates/falcon-ifc/cpp/worker.cpp` into `falcon-ifc-worker`, a separate executable falcon starts for each read; nothing of web-ifc is linked into falcon's own binaries. Without those sources no worker is built and reads only tessellated IFC geometry. web-ifc and CDT are covered by the Mozilla Public License 2.0 (<https://mozilla.org/MPL/2.0/>); falcon uses them unmodified and their source code is available from the URLs above. `scripts/bundle.sh` copies the licence text of each of these components into `Falcon.app/Contents/Resources/web-ifc` when the worker is there. Falcon's own files are not covered by the MPL.

FFmpeg is not part of falcon's source and is never linked into it. `scripts/build-ffmpeg.sh` downloads the release above, checks its SHA-256 (`de668509caf9e35e3cd162473441fdb29538c6d96ed080292b3cf9e6fc5d558f`) and builds it without GPL or nonfree parts and without encoders, muxers or programs; the exact configure line is in that script and in `docs/src/video.md`. `scripts/bundle.sh` copies the resulting shared libraries, unmodified, into `Falcon.app/Contents/Frameworks` and puts the LGPL text and a note of the version, source and configure line in `Contents/Resources/FFmpeg` (`COPYING.LGPLv2.1.txt`, `BUILD-INFO.txt`). falcon opens them with `dlopen` and refuses any build whose licence string is not the LGPL. The FFmpeg source can be obtained from the URL above or from <https://ffmpeg.org/download.html>; the libraries can be replaced with any compatible FFmpeg 7.1 build.

dav1d (Copyright © 2018-2025, VideoLAN and dav1d authors, BSD 2-Clause License) is not part of falcon's source either. `scripts/build-ffmpeg.sh` downloads the release above, checks its SHA-256 (`686616b7c69eb88d44459391ab25cac13b6647a3b288835c5784e71c1514a5c5`, as published by VideoLAN and recorded by MacPorts), builds it with meson and ninja (pinned wheels in a venv under `target/`) as a shared library, and links libavcodec against it with `--enable-libdav1d`. `scripts/bundle.sh` copies `libdav1d.7.dylib`, unmodified, into `Falcon.app/Contents/Frameworks` and its licence text into `Contents/Resources/FFmpeg/COPYING.dav1d.txt`; `BUILD-INFO.txt` there records its version, source, hash and build options.

The AV1 test clip `crates/falcon-ffmpeg/testdata/av1.ivf` was made for falcon's tests from flat synthesised pictures, encoded with rav1e 0.8.1 (BSD-2-Clause, [github.com/xiph/rav1e](https://github.com/xiph/rav1e)), which is not linked into falcon.
